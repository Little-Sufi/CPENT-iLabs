Perimeter Defence Evasion Techniques

Scenario

In today’s rapidly evolving threat landscape, perimeter defense devices such as firewalls and intrusion detection systems (IDS) serve as the first line of defense against cyber threats. However, attackers continuously develop sophisticated techniques to evade these defenses, rendering traditional configurations ineffective. Conducting penetration testing of these devices is crucial to identify vulnerabilities, misconfigurations, and potential bypass methods before attackers can exploit them. A proactive penetration test helps simulate real-world attack scenarios, such as advanced evasion techniques, misconfigured access control rules, or outdated firmware, enabling organizations to understand their exposure and take corrective actions. This approach strengthens overall security posture by ensuring that perimeter defense devices effectively detect and mitigate modern threats.

Investing in penetration testing of firewalls and IDS solutions also provides tangible business benefits by reducing the risk of data breaches and minimizing potential downtime from successful attacks. It enables organizations to validate compliance with security regulations and industry standards, such as PCI DSS or ISO 27001, which often mandate periodic testing of network defenses. Moreover, the insights gained from such testing allow IT teams to optimize defense configurations, ensuring resources are allocated efficiently and operational gaps are addressed promptly. By identifying weaknesses in perimeter defenses, organizations can not only protect their sensitive assets but also maintain customer trust and business continuity in the face of ever-evolving cyber threats.

Objective

The objective of this module is to help students learn different techniques to evade perimeter defences. You will learn how to:

  • Scan with Nmap against Defenses

  • Identify and Bypass a Firewall

  • Use HTTP Tunneling to Bypass Firewalls Using HTTPort

  • Perform evasion Using Social-Engineer Toolkit (SET)

  • Use Proxychains to Avoid Detection

  • Perform WAF Fingerprint

  • Enumeate Firewall Access Control List and Bypass WAF using Nmap

Note: All lab manuals are accessible in the Lab Manuals folder located on the Desktop of the machines. Please refer to the respective lab manual if you need to copy and paste any commands or code during the lab sessions.

Exercise 1: Scanning against Defenses with Nmap

Scenario

One of the most popular open source scanning tools on the market is Nmap. As you may have discovered, it is an effective tool. We have also, on numerous occasions, discovered that if there are defenses in place such as firewalls or filters, conducting scans becomes more challenging.

During a penetration test, it is imperative that you use a tool to identify open ports and the services attached to that port. There are a number of tools available, and we will start with the most popular tool on the market that is free and open source: Nmap. Nmap also has options that give it better success when encountering filters.

Exercise 2: Identifying and Bypassing a Firewall

Attackers are constantly searching for vulnerable clients to penetrate their network through IP spoofing to damage or steal data. The attackers can access packets through a firewall by spoofing the IP address. If attackers are able to capture network traffic, as explained in the previous lab, they can perform Trojan attacks, registry attacks, password hijacking attacks, etc., which can be disastrous for an organization’s network.

Therefore, as a network administrator you should be able to identify attacks by extracting information from captured traffic such as source and destination IP addresses, protocol type, header length, source and destination ports, etc. and compare these details with modeled attack signatures to detect if an attack has occurred.

Exercise 5: Using Proxychains to Avoid Detection and Bypass Perimeter Defences

Scenario

As a penetration tester, you need to assess the security of a high-profile organization that employs multiple layers of network defenses, including firewalls, IDS/IPS, and IP-based geolocation restrictions. Your reconnaissance may indicate that the organization's perimeter defenses block direct connections from unknown or suspicious IP addresses, effectively preventing external scans or unauthorized access attempts. To overcome this challenge, you can use Proxychains to route your traffic through multiple proxy servers, disguising your original IP and avoiding detection. By chaining proxies located in different geographic regions, you successfully bypass IP-based restrictions while maintaining anonymity.

Detection involves recognizing WAF signatures and behaviors. Bypassing techniques exploit weaknesses or use obfuscation to evade WAF filters, relying on a deep understanding of the WAF's rules and configurations.

Exercise 7: Enumeating Firewall Access Control List and Bypassing WAF using Nmap

In the previous lab we have detected the WAF on www.certifiedhacke.com, now, we will perfom nmap scans beyond those WAF to gather open ports and other information.

Lab Tasks

  1. In the Parrot Security machine, open a terminal window with sudo privileges, and run nmap -sS -O certifiedhacker.com to perform a SYN Stealth scan.

    In the above command, -sS performs a SYN scan, and -O performs OS detection.

  2. To scan a specific port, use the nmap -sS -O certifiedhacker.com -p 80 command.

  3. Now, we will try to bypass the firewall using fragmented packets. To do so, run the nmap -f certifiedhacker.com command.

    The -f option is used to send fragmented packets.

  4. To send fragmented packets by setting a specific MTU, run the nmap -mtu 24 certifiedhacker.com command.

    -mtu stands for Maximum Transmission Unit.

  5. Now, we will try to bypass the firewall by spoofing the source port. To do so, run the nmap --source-port 53 certifiedhacker.com command.

  6. We will try to bypass the firewall by MAC address spoofing by specifying a MAC address from a vendor. To do so, run the nmap -sT -Pn --spoof-mac Dell certifiedhacker.com command.

    The -sT performs a TCP connect scan, -Pn disables host discovery, and --spoof-mac Dell spoofs the MAC address of a Dell vendor.

  7. This concludes enumerating the access control list and bypassing the Web Application Firewall using Nmap.

  8. Close all open windows.
