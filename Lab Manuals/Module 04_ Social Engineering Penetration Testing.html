Module 04: Social Engineering Penetration Testing Methodology

Scenario

The main objective of social engineering penetration testing is to check the loyalty of employees in the organization, their awareness regarding phishing attacks, their ability to comply with security policies, and the application of their security training. Penetration testers may employ various techniques involving the use of phones, and physical, and internet-based engagements with the employees, to identify those who fall prey to these techniques. To perform social engineering pen testing, testers must gather all the information of the victim and use this information to gather sensitive organization data.

As a penetration tester, you must know how to crack cloned malicious login pages, mask the cloned webpage URLs, and entice the employees in an organization to click them.

Objective

This module aims to help students learn different techniques to gather information about a user. You will learn how to:

  • Conduct a Phishing Campaign Using Social Engineering Toolkit

  • Conduct a Phishing Campaign Using Dark-Phish

Note: All lab manuals are accessible in the Lab Manuals folder located on the Desktop of the machines. Please refer to the respective lab manual if you need to copy and paste any commands or code during the lab sessions.

Exercise 1: Sniff credentials using the Social-Engineer Toolkit (SET)

The Social-Engineer Toolkit (SET) is an open-source Python-driven tool aimed at penetration testing via social engineering. SET is useful to attackers because it is freely available and can be used to carry out a range of attacks. For example, it allows attackers to compose phishing email messages, attach malicious files, and send them to many people using spear phishing. Additionally, SET’s multi-attack method allows Java applets, the Metasploit browser, and Credential Harvester/Tabnabbing to be used simultaneously. SET categorizes attacks based on the attack vector used, such as email, web, and USB.

While SET can be used to carry out a variety of attacks, it is also an essential tool for penetration testers to identify vulnerabilities. For this reason, SET is the industry standard for social engineering penetration tests and is widely supported within the security community.

As an ethical hacker, penetration tester, or security administrator, you should be familiar with SET and be able to use it to perform various tests for network vulnerabilities.

Here, we will sniff user credentials using the SET.

Objective

  • Sniffing User Credentials using SET's Site Cloner

  • Sniffing user credentials using SET's QRCode Generator Attack Vector

Task 1: Sniffing User Credentials using SET's Site Cloner

  1. Click on Parrot Security to switch to the Parrot Security machine. Login using pentester/toor.

If a Question pop-up window appears asking you to update the machine, click No to close the window.

  1. Open a Terminal window and execute sudo su to run the programs as a root user (When prompted, enter the password toor).

The password that you type will not be visible.

  1. Run setoolkit to launch Social-Engineer Toolkit.

If a Do you agree to the terms of service [y/n] question appears, enter y and press Enter.

  1. The SET menu appears as shown in the screenshot below. Type 1 and press Enter to choose Social-Engineering Attacks.

  2. A list of options for Social-Engineering Attacks appears; type 2 and press Enter to choose Website Attack Vectors.

  3. A list of options in Website Attack Vectors appears; type 3 and press Enter to choose Credential Harvester Attack Method.

  4. Type 2 and press Enter to choose Site Cloner from the menu.

  5. Type the IP address of the local machine (192.168.0.18) in the prompt for “IP address for the POST back in Harvester/Tabnabbing” and press Enter.

In this case, we are targeting the Parrot Security machine (IP address: 192.168.0.18).

  1. Now, you will be prompted to enter the URL to clone. Type the desired URL in the Enter the url to clone field and press Enter. In this task, we will clone the URL http://www.moviescope.com.

You can clone any URL of your choice.

  1. After cloning is completed, the credential harvester initiates as shown in the screenshot.

  2. Having successfully cloned a website, you must now send the IP address of your Parrot Security machine to a victim and try to trick them into clicking on the link.

  3. Click the Firefox icon from the top section of the Desktop to launch a web browser window and open your email account (in this example, we will be using Mozilla Firefox and Outlook). Log in and compose an email.

You can log in to any email client of your interest.

  1. After logging into your email account, click the New Mail button in the left pane and compose a fake but enticing email to lure a user into opening the email and clicking on a malicious link.

  2. One method to disguise a malicious link in a message is to use text that appears to be a legitimate MovieScope URL. However, the hyperlink can redirect users to a cloned, malicious version of the MovieScope page instead.

  3. Position the cursor just above Regards to place the fake URL, then click the Insert link icon.

  4. In the Insert link window, first enter the fake URL in the Display as field. Next, input the actual address of your cloned site in the Web address (URL) field and click OK. In this case, the text displayed in the message will be www.moviescope.com/account-information, while the actual address of the cloned MovieScope site is http://192.168.0.18.

  5. The fake URL should appear in the message body.

  6. Verify that the fake URL is linked to the correct cloned site: in Outlook, hover over the link; the actual URL will be displayed. Once verified, send the email to the intended user.

  7. Click Windows Server 2022 to switch to the Windows machine and log in using Admin/Pa$$w0rd.

  8. Open any web browser (here, we are using Google Chrome), and sign in to the email account to which you sent the phishing mail as an attacker. Open the email you sent previously and click to open the malicious link.

  9. When the victim (you in this case) clicks the URL, a new tab opens, and the victim sees a replica of www.moviescope.com.

  10. The victim will be prompted to enter the username and password into the form fields, which appear as they do on the genuine website. When the victim enters the credentials and clicks Login, they will be redirected to the legitimate MovieScope login page. Note the different URLs in the browser address bar for the cloned and legitimate sites.

  11. Now, click on Parrot Security to switch back to the Parrot Security machine and switch to the terminal window.

  12. Soon after the victim types in the Username and Password and clicks Login, SET records the credentials. The attacker can then use them to gain unauthorized access to the victim's account.

  13. Scroll down to find the Username and Password displayed in plain text, as shown in the screenshot.

  14. Now, hit Ctrl+C and then, press Enter to return to the previous menu.

  15. Keep hitting Ctrl+C or keep entering 99 in the SET terminal until you come out of the SET terminal.

  16. Keep all current windows open as the next section builds on the content of this section.

  1. File Upload window appears, navigate to /root/.set/reports, select qrcode_attack.jpg and click Open.

Exercise 2: Sniff Credentials using Dark-Phish

Dark-Phish is a specialized phishing tool designed for educational purposes and security testing. It is capable of simulating phishing attacks and facilitating the evaluation of system vulnerabilities and user awareness levels.

Here, we will sniff user credentials using Dark-Phish.

  1. On Parrot Security, open a Terminal window, and execute sudo su to run the programs as a root user (When prompted, enter the password toor).

  2. Run cd Dark-Phish/ to navigate to Dark-Phish directory.

  3. In this task, we will be hosting the PHP server on the local host. To do so, we need to change the localhost IP address in the darkphish.py file.

  4. In the terminal window, type pluma dark-phish.py to edit the Python script in the Pluma text editor.

  5. In the text editor, replace 127.0.0.1 with 172.19.19.18 in line 30 under the host field, save the file, and close the text editor window.

  6. Launch Dark-Phish by executing the python3 dark-phish.py command.

  7. The Dark-Phish menu appears as shown in the screenshot. You can observe numerous platform options presented by Dark-Phish. Now, type 06 and press Enter to choose Google.

  8. A list of hosting options appears; type 01 and hit Enter to choose Localhost.

  9. Modify the URL (Y/N) option appears; type N and press Enter.

  10. Send link appears. Having successfully generated a phishing link, you must now send this link to a victim and try to trick them into clicking it. So, copy the link.

  11. Launch a web browser (here, Mozilla Firefox) and open your email account (in this example, we are using Outlook). Log in and compose an email.

You can log in to any email service of your preference.

  1. After logging into your email account, click the New Mail button in the left pane and compose a fake but enticing email to lure a user into opening the email and clicking on a malicious link.

One method to conceal a malicious link in a message is to use text that appears to be a legitimate MovieScope URL. However, the hyperlink can redirect users to a cloned, malicious version of the MovieScope page instead.

When the victim enters the Username and Password and signs into it, they will be redirected to the legitimate Google page.
