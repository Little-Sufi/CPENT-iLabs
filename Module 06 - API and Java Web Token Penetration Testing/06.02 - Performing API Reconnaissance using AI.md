### Scenario

API reconnaissance is a critical preliminary step in web service penetration testing. Modern API frameworks (such as Swagger/OpenAPI, GraphQL, and gRPC) expose endpoints, data models, and authentication mechanisms through structural metadata.

Artificial Intelligence tools like **ShellGPT** (`sgpt`), driven by large language models (such as GPT-4), allow penetration testers to generate context-aware reconnaissance scripts on the fly. By translating natural language security prompts into executable shell pipelines, ShellGPT automates the extraction of API routes, structural enumeration, endpoint identification, and technology fingerprinting against target API services like <font color="#38bdf8"><b>https://petstore.swagger.io/</b></font>.

In this exercise, we initialize ShellGPT with an activation key on Parrot Security, generate an automated API reconnaissance script, execute the commands, and save the structured enumeration output to <font color="#c084fc"><b>api_recon_results.txt</b></font>.

### Objective

The objective of this lab is to help students learn how to:
- Configure and authenticate the ShellGPT (`sgpt`) AI integration tool on Parrot Security
- Formulate natural language shell generation prompts (`sgpt --shell`) for target API reconnaissance
- Automate the discovery of API endpoints, routing structures, and underlying technologies against <font color="#38bdf8"><b>https://petstore.swagger.io/</b></font>
- Execute AI-generated bash pipelines and inspect structured output logs (<font color="#c084fc"><b>api_recon_results.txt</b></font>)
