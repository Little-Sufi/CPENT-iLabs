### Scenario

OS Command Injection vulnerability occurs when a web application passes unsafe, user-supplied data directly to a system shell (such as Windows `cmd.exe` or Linux `bash`) for execution without proper sanitization or input validation.

Attackers exploit command injection vulnerabilities by injecting command separator characters (such as `|`, `;`, `&&`, `&`, or `||`) into input fields (e.g., ping forms), allowing them to append arbitrary operating system commands. In Windows environments, this grants unauthorized access to system information, process management, user accounts, security policies, and filesystem structures.

In this exercise, we perform command injection attacks against **DVWA** (set to Low security) hosted on Windows Server 2019, chaining Windows CLI utility commands (`hostname`, `whoami`, `tasklist`, `taskkill`, `dir`, `net user`, and `net accounts`) to extract host configuration and identify the target machine's computer role as <font color="#ffd700"><b>SERVER</b></font>.

### Objective

The objective of this lab is to help students learn how to:
- Identify unvalidated input fields passing user input directly to OS shell interpreters
- Use command separator operators (`|`, `&&`, `&`) to chain arbitrary system commands
- Enumerate host information (`hostname`, `whoami`, process trees `tasklist`)
- Manage remote processes (`taskkill`) and inspect filesystem directories (`dir C:\`)
- Extract local user accounts (`net user`) and remote domain/system security policies (`net accounts`)

## Task 1: Performing OS Command Injection Attacks on a Target

In this task, we navigate to the Command Injection section of DVWA on Parrot Security (`http://192.168.0.20:8080/dvwa`), input baseline ping targets, append chained commands using the pipe (`|`) operator to enumerate system information, terminate running processes, inspect directory listings, and extract password policies revealing the Computer role (<font color="#ffd700"><b>SERVER</b></font>).

### Lab Tasks

3. In the **Ping a device** input field, enter <font color="#38bdf8"><b>192.168.0.18</b></font> and click **Submit**.
