### Scenario

Local File Inclusion (LFI) vulnerability occurs when a web application dynamically incorporates local files into page execution without proper validation or sanitization of user-supplied input. This allows an attacker to manipulate file path parameters (such as `language` or `page`) to read sensitive system configuration files (e.g., `/etc/passwd`, database credentials, or application source code) hosted on the web server.

In this exercise, we deploy the **bWAPP** (buggy Web Application) container on Ubuntu and exploit an LFI vulnerability from Parrot Security to extract the target system's `/etc/passwd` file.

### Objective

The objective of this lab is to help students learn how to:
- Deploy and initialize the bWAPP vulnerable web application using Docker
- Identify unvalidated parameter queries in Remote & Local File Inclusion (RFI/LFI) modules
- Execute Local File Inclusion (LFI) attacks via direct URL parameter manipulation to extract sensitive Linux system files (`/etc/passwd`)

## Task 1: Performing a Local File Inclusion (LFI) Attack
