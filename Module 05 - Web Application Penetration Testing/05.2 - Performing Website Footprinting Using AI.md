### Scenario

In this lab, we will use AI tools such as ChatGPT to generate a Python script for performing comprehensive website footprinting and enumeration. The script will automate tasks such as analyzing HTML source code, identifying server-side technologies, crawling the website, extracting metadata, and testing for protections like WAFs and load balancers.

### Objective

The objective of this lab is to help students learn how to leverage AI models to generate customized Python scripts for comprehensive website footprinting and security analysis.

---

## Task 1: Performing Website Footprinting Using AI

In this task, we generate and execute a custom Python script to perform automated website footprinting on the target domain `www.luxurytreats.com`.

### Lab Tasks
1. In the **Parrot Security** machine, open **Mozilla Firefox**, type <font color="#38bdf8"><b>https://chatgpt.com/</b></font>, and press Enter.

![Screenshot](../Lab%20Manuals/Module%2005_%20Web%20Application%20Penetration%20Testing_files/iox4eyqe.jpg)

2. In the Message ChatGPT text box enter the below sample prompt and press Enter or click on the Up arrow button for generating a Python script to perform Website Footprinting of a target website:

```text
Generate a Python script to gather information from the target website. The script should prompt for the input URL and perform the following tasks sequentially:
1. Perform website footprinting.
2. Perform website enumeration.  
3. Analyze the HTML source code.
4. Check HTTP/HTML processing by the browser. 
5. Identify server-side technologies.
6. Mirror and crawl the website to identify files, directories, and folders.
7. Identify the sitemap.
8. Extract a common word list.
9. Extract metadata and hidden information.
10. Test whether the Target Website is Protected using a Web Application Firewall (WAF).
11. Test whether the Target Website is Protected using Load Balancers.
12. Perform HTTP service discovery.
13. Perform banner grabbing.  
14. Enumerate web server directories.
15. Test for proxy functionality. 
This script should save the output in 'Information_Gathered.txt' in a structured format. The script should install all the required dependencies and libraries.
```

![Screenshot](../Lab%20Manuals/Module%2005_%20Web%20Application%20Penetration%20Testing_files/zamaoxtv.jpg)

3. Now, copy and save the generated Python Script in a text file named <font color="#c084fc"><b>Website_Footprinting.py</b></font>.
   - You can run the sample Python script that is already saved and available in your local repository at:
     `CPENTv2 Pen Testing Resources/CPENTv2 Scripts/Module 05 Web Application Penetration Testing/Website_Footprinting.py`

4. Launch the command-line terminal, type <font color="#ffd700"><b>sudo su</b></font> and press Enter. Enter <font color="#ff4d4d"><b>toor</b></font> as the password.

6. Enter <font color="#38bdf8"><b>http://luxurytreats.com</b></font> as the target URL.
