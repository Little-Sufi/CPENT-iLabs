# Exercise 8: Directory Browsing a WordPress Website using DirBuster and Accessing Shell

### Scenario

This lab is a continuation of **Exercise 05.7**. In the previous lab exercise, you learned how to edit theme files and upload a custom PHP command shell. A penetration tester needs to determine the directory structure of a web application to find hidden or accessible sensitive folders and files.

In this lab, you will learn how to perform automated directory browsing using DirBuster to discover the uploaded shell location (`404.php`), access it via a web browser, and execute system-level commands to gain remote access to the host server.

### Objective

The objective of this lab is to help students learn how to:
- Use DirBuster to perform directory and file brute-forcing on web applications
- Locate uploaded web shells within theme directories (`/wp-content/themes/twentyfifteen/404.php`)
- Execute remote system commands via HTTP GET parameters to verify Remote Code Execution (RCE)

---

## Task 1: Directory Browsing a WordPress Website using DirBuster and Accessing Shell

In this task, we launch DirBuster against `http://www.cpent.com`, brute-force web directories to locate the `TwentyFifteen` theme directory, and access `404.php?cmd=whoami` to obtain the current user context from the target server.

### Lab Tasks
1. Click **Parrot Security**. Type <font color="#ff4d4d"><b>toor</b></font> in the Password field and press Enter.
   - *(If you are already logged in, skip to step 2.)*

![Screenshot](../Lab%20Manuals/Module%2005_%20Web%20Application%20Penetration%20Testing_files/2kldcojv.jpg)

2. Launch a command-line terminal, type <font color="#ffd700"><b>sudo su</b></font> and press Enter. Enter <font color="#ff4d4d"><b>toor</b></font> as the password.

![Screenshot](../Lab%20Manuals/Module%2005_%20Web%20Application%20Penetration%20Testing_files/5uyk5vpq.jpg)

3. Type <font color="#ffd700"><b>dirbuster</b></font> and press Enter to launch the graphical interface.

![Screenshot](../Lab%20Manuals/Module%2005_%20Web%20Application%20Penetration%20Testing_files/xvu0o5am.jpg)

4. In the DirBuster main window, type <font color="#38bdf8"><b>http://www.cpent.com</b></font> in the **Target URL** field.

![Screenshot](../Lab%20Manuals/Module%2005_%20Web%20Application%20Penetration%20Testing_files/cguz0rgs.jpg)

5. Configure scan settings:
   - Select **Pure Brute Force** radio button in the **Select scanning type** section
   - Select **a-z0-9** from the **Char set** drop-down list
   - Set **Min Length** to <font color="#ffd700"><b>1</b></font> and **Max Length** to <font color="#ffd700"><b>20</b></font>
   - Check **Use Blank Extension** option
6. Click **Start** to initiate directory brute-forcing.

![Screenshot](../Lab%20Manuals/Module%2005_%20Web%20Application%20Penetration%20Testing_files/xvld1lml.jpg)

7. DirBuster begins brute forcing directories and files, displaying status in the **Scan Information** tab.

![Screenshot](../Lab%20Manuals/Module%2005_%20Web%20Application%20Penetration%20Testing_files/dr3barrb.jpg)

8. Click the **Results - List View** tab to monitor discovered files and directories.

![Screenshot](../Lab%20Manuals/Module%2005_%20Web%20Application%20Penetration%20Testing_files/jglbkxth.jpg)

9. Scroll through the **Results - List View** tab to identify the theme directory <font color="#c084fc"><b>twentyfifteen</b></font>.

![Screenshot](../Lab%20Manuals/Module%2005_%20Web%20Application%20Penetration%20Testing_files/f15p0wkf.jpg)

10. Click the **Results - Tree View** tab to examine the full directory path structure. The path to the TwentyFifteen theme is identified as:
    <font color="#c084fc"><b>/wp-content/themes/twentyfifteen/</b></font>

![Screenshot](../Lab%20Manuals/Module%2005_%20Web%20Application%20Penetration%20Testing_files/zwkyubmq.jpg)

11. Open Firefox web browser and navigate to:
    <font color="#38bdf8"><b>http://www.cpent.com/wp-content/themes/twentyfifteen/404.php</b></font>

![Screenshot](../Lab%20Manuals/Module%2005_%20Web%20Application%20Penetration%20Testing_files/0lmq4rmr.jpg)

12. Test remote command execution by appending the `cmd` GET parameter to the URL:
    <font color="#38bdf8"><b>http://www.cpent.com/wp-content/themes/twentyfifteen/404.php?cmd=whoami</b></font>

![Screenshot](../Lab%20Manuals/Module%2005_%20Web%20Application%20Penetration%20Testing_files/frkvt1f5.jpg)

13. Press Enter and observe the output returned by the web shell: <font color="#ffd700"><b>www-data</b></font>.

![Screenshot](../Lab%20Manuals/Module%2005_%20Web%20Application%20Penetration%20Testing_files/ysaca4id.jpg)

14. This confirms successful Remote Code Execution via the uploaded PHP shell. Close all open windows.

This concludes the lab exercise.
