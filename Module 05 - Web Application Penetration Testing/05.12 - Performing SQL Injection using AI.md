# Exercise 12: Performing SQL Injection using AI

### Scenario

In this exercise, we will use **ShellGPT (`sgpt`)** to perform automated SQL injection. ShellGPT is an AI-powered command-line interface leveraging OpenAI GPT-4 to generate and execute shell commands and penetration testing workflows automatically based on natural language prompts.

By combining AI prompt engineering with penetration testing tools like `sqlmap`, security assessors can automate complex multi-stage attack parameters, vulnerability checks, and database enumeration.

### Objective

The objective of this lab is to help students learn how to:
- Configure ShellGPT (`sgpt`) with an AI activation API key on Parrot Security
- Formulate natural language prompts to perform Boolean-based, UNION-based, Error-based, and Time-based blind SQL injection checks
- Automate database enumeration on vulnerable targets (`http://testphp.vulnweb.com/listproducts.php?cat=1`)
- Analyze `sqlmap_results.txt` output and identify web server software versions (Nginx)

---

## Task 1: Performing SQL Injection using AI

In this task, we configure ShellGPT on Parrot Security using `sgpt.sh`, issue a natural language prompt instructing `sgpt` to run `sqlmap` against the vulnerable target URL `http://testphp.vulnweb.com/listproducts.php?cat=1`, and extract target database and server information (Nginx version).

### Lab Tasks

```bash

Save the output in a text file with a structured format"
```
