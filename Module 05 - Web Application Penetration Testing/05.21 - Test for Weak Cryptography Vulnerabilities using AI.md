### Scenario

Testing web applications for weak cryptography and transport layer security misconfigurations is an essential phase of web application penetration testing. Cryptographic vulnerabilities—such as support for deprecated SSL/TLS protocols (SSLv2, SSLv3, TLS 1.0, TLS 1.1), weak cipher suites (e.g., RC4, 3DES, EXPORT ciphers), and unencrypted data transmission—expose sensitive user traffic to eavesdropping and Man-in-the-Middle (MitM) attacks.

Generative AI platforms (such as ChatGPT) can be used to generate automated bash scripts that streamline SSL/TLS testing tools (e.g., `sslscan`, `testssl.sh`, or `nmap` SSL scripts), combining transport security evaluations into a single execution workflow.

In this exercise, we generate and run `TestWeakCryptography.sh` against target domain <font color="#38bdf8"><b>www.certifiedhacker.com</b></font>, logging transport layer auditing results (`Transport_Layer_Security_Results.txt`) to determine the target host's IP address (<font color="#ffd700"><b>162.241.216.11</b></font>).

### Objective

The objective of this lab is to help students learn how to:
- Leverage AI tools (ChatGPT) to generate shell scripts automating cryptographic vulnerability assessments
- Audit target web applications for insufficient transport security, weak ciphers, and unencrypted transmission
- Execute Unix-formatted shell scripts (`TestWeakCryptography.sh`) using `dos2unix` and `chmod`
- Analyze output logs (`Transport_Layer_Security_Results.txt`) to extract target host IP resolution (<font color="#ffd700"><b>162.241.216.11</b></font>)

4. Review the generated script structure:

```bash
#!/bin/bash
# TestWeakCryptography.sh - Automated Cryptographic Vulnerability Audit

echo "=================================================="
echo " Cryptographic & Transport Layer Security Audit   "
echo "=================================================="

read -p "Enter Target Domain/URL (e.g., www.certifiedhacker.com): " TARGET_HOST
OUTPUT_FILE="Transport_Layer_Security_Results.txt"

# Install dependencies if missing
apt-get update && apt-get install -y sslscan nmap

echo "Auditing Transport Layer Security & SSL/TLS Ciphers..." | tee -a $OUTPUT_FILE
sslscan $TARGET_HOST | tee -a $OUTPUT_FILE

echo -e "
Running Nmap Cipher Enum Scripts..." | tee -a $OUTPUT_FILE
nmap --script ssl-enum-ciphers -p 443 $TARGET_HOST | tee -a $OUTPUT_FILE

echo -e "
Audit Complete. Output saved to $OUTPUT_FILE."
```
