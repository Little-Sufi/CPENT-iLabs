### Scenario

In this lab, we perform UNION-based SQL injection attacks against the OWASP Juice Shop application to extract database schema definitions and dump user credential tables.

SQL Injection (SQLi) occurs when untrusted user input is directly concatenated into a backend database query without adequate sanitization or parameterization. Attackers can leverage SQLi to bypass authentication, read arbitrary database tables, and extract sensitive information such as password hashes and API secrets.

### Objective

The objective of this lab is to help students learn how to:
- Identify SQL Injection vulnerabilities in RESTful API endpoints (`/rest/products/search?q=`) using Burp Suite Repeater
- Determine query column count using `UNION SELECT` statement column-matching techniques
- Enumerate SQLite database schema via the `sqlite_master` table
- Extract user accounts, role definitions, and password hashes from the backend `Users` table

## Task 1: Extracting the Database Schema and List of User Credentials via SQL Injection

In this task, we launch the OWASP Juice Shop container, capture product search requests via Burp Suite Proxy, manipulate search parameters in Repeater to trigger SQLite syntax errors, determine column positioning, extract table schemas from `sqlite_master`, and dump all rows from the `Users` table.
