### Scenario

Assessing web application deployment configurations and identifying unreferenced files or backup archives are critical steps in web vulnerability scanning. Platform configuration audits uncover server header disclosures, insecure HTTP options, outdated web server software, and misconfigured file extensions.

Generative AI platforms (such as ChatGPT) can be leveraged by security professionals to quickly generate automated shell scripts that combine multiple security scanners—such as **Nikto** (for web server configuration and file extension audits) and **Gobuster** (for brute-forcing unreferenced directories and backup files).

In this exercise, we generate and execute a custom automation bash script (`TestConfiguration.sh`) against <font color="#38bdf8"><b>http://luxurytreats.com</b></font> to automate configuration scanning, directory enumeration, and report logging to extract web server version information (<font color="#ffd700"><b>Microsoft-IIS/7.5</b></font>).

### Objective

The objective of this lab is to help students learn how to:
- Prompt AI tools (ChatGPT) to generate structured shell scripts combining Nikto and Gobuster
- Prepare and convert shell scripts to Unix format (`dos2unix`) and set execution permissions (`chmod +x`)
- Perform automated web platform configuration checks and unreferenced file discovery against a target application
- Analyze audit results (`WebApp_Test_Results.txt`) to identify target web server software versions (<font color="#ffd700"><b>7.5</b></font>)

```bash
#!/bin/bash
# TestConfiguration.sh - Automated Web Application Audit Script

echo "=================================================="
echo " Web Application Configuration & Reconnaissance   "
echo "=================================================="

read -p "Enter Target URL (e.g., http://luxurytreats.com): " TARGET_URL
OUTPUT_FILE="WebApp_Test_Results.txt"

echo "Running Platform Configuration Scan with Nikto..." | tee -a $OUTPUT_FILE
nikto -h $TARGET_URL | tee -a $OUTPUT_FILE

echo -e "
Running File Extension Handling Audit..." | tee -a $OUTPUT_FILE
nikto -h $TARGET_URL -Plugins "tests(file_extensions)" | tee -a $OUTPUT_FILE

echo -e "
Discovering Old Backups & Unreferenced Files with Gobuster..." | tee -a $OUTPUT_FILE
gobuster dir -u $TARGET_URL -w /usr/share/wordlists/dirb/common.txt -x php,bak,old,zip,txt | tee -a $OUTPUT_FILE

echo -e "
Audit Complete. Results saved to $OUTPUT_FILE."
```
