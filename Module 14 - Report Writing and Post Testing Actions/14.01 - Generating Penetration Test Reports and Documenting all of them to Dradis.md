### Scenario

**Dradis Collaborative Report Generation & Pentest Data Consolidation** utilizes the Dradis Framework web application (`http://127.0.0.1:3000`) to aggregate, structure, tag, and export security assessment findings into comprehensive, multi-audience penetration testing reports.

Key technical concepts in Dradis pentest report generation:
1. **Dradis Service Initialization**: Starting the Dradis Ruby web service via <font color="#ffd700"><b>sudo dradis</b></font> on **Parrot Security** VM, spawning a local web app server on port `3000`.
2. **Metadata & Executive Summary Structuring**: Creating custom issue fields in Dradis to store document control parameters (Company: `X-SECURITY`, Recipient: `Luxurytreats`, Date: `August 18, 2020`, Classification: `Confidential`, Author: `John`, Testers: `Micheal, Marshall, Sean, Adam`) and executive summaries.
3. **Automated Tool Output Ingestion**: Utilizing Dradis upload plugins—specifically <font color="#c084fc"><b>Dradis::Plugins::Nmap</b></font>—to parse XML scan files (<font color="#c084fc"><b>/home/pentester/scan.xml</b></font>) and automatically import discovered open ports, services, and vulnerability findings into the issue database.
4. **Issue Classification & Tagging**: Tagging issues with severity indicators (`Info`, `Critical`) and drafting comprehensive technical report entries.
5. **Report Export Engine**: Rendering the aggregated project database via <font color="#c084fc"><b>default_dradis_template_v3.0.html.erb</b></font> template to produce a standalone HTML report file for client delivery.

In this exercise, we launch Dradis (`sudo dradis`), log into the web GUI (`Admin` / <font color="#ff4d4d"><b>password</b></font>), structure project metadata and executive summaries, upload Nmap scan XML (`scan.xml`), classify issue severity tags, and export the finalized HTML penetration test report.

### Objective

The objective of this lab is to help students learn how to:
- Launch and authenticate to Dradis framework (`http://127.0.0.1:3000`)
- Structure project metadata, document details, and executive summaries
- Ingest external scanner outputs using <font color="#c084fc"><b>Dradis::Plugins::Nmap</b></font> plugin
- Parse XML scan file: <font color="#c084fc"><b>/home/pentester/scan.xml</b></font>
- Apply issue severity tags (`Info`, `Critical`)
- Draft comprehensive technical findings
- Export consolidated HTML penetration test report using <font color="#c084fc"><b>default_dradis_template_v3.0.html.erb</b></font> template
