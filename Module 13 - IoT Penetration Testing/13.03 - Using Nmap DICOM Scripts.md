### Scenario

**Healthcare IoT Auditing with Nmap Scripting Engine (NSE)** utilizes specialized NSE scripts to discover, audit, and evaluate security posture across medical imaging devices running **DICOM** (Digital Imaging and Communications in Medicine) protocol services.

Key technical concepts in DICOM Nmap scanning:
1. **NSE Script Location & Inventory**: Locating built-in DICOM NSE scripts in <font color="#c084fc"><b>/usr/share/nmap/scripts/</b></font> using wildcard search (`ls *dicom*`).
2. **NSE Lua Logic Auditing**: Inspecting script internals (<font color="#c084fc"><b>dicom-ping.nse</b></font>) via text editors (`pluma`) to analyze PDU handshake verification and Application Entity Title (AET) probe parameters.
3. **Target Port Fingerprinting**: Scanning medical target servers (e.g., Orthanc DICOM server running on port <font color="#38bdf8"><b>4242</b></font>) using <font color="#ffd700"><b>nmap -sV -p 4242 --script dicom-ping [Target_IP]</b></font>.
4. **Service Vulnerability Reporting**: Identifying open, unauthenticated DICOM daemon endpoints that expose sensitive Electronic Protected Health Information (ePHI) or lack encryption transport protocols.

In this exercise, we log into **Parrot Security** (<font color="#c084fc"><b>pentester</b></font> / <font color="#ff4d4d"><b>toor</b></font>), navigate to `/usr/share/nmap/scripts/`, list DICOM scripts, inspect `dicom-ping.nse` source code, execute `nmap` service detection and `dicom-ping` NSE audit against Ubuntu DICOM server on TCP port <font color="#38bdf8"><b>4242</b></font>, and record service status reports.

### Objective

The objective of this lab is to help students learn how to:
- Authenticate to Parrot Security target VM (<font color="#c084fc"><b>pentester</b></font> / <font color="#ff4d4d"><b>toor</b></font>)
- Navigate to Nmap scripts directory: <font color="#ffd700"><b>cd /usr/share/nmap/scripts</b></font>
- List available DICOM NSE scripts: <font color="#ffd700"><b>ls *dicom*</b></font>
- Inspect NSE script logic using Pluma editor: <font color="#ffd700"><b>pluma dicom-ping.nse</b></font>
- Scan target Ubuntu medical server: <font color="#ffd700"><b>nmap -sV -p 4242 --script dicom-ping 192.168.0.x</b></font>
- Identify listening DICOM service port (<font color="#38bdf8"><b>4242</b></font>) and assess security compliance
