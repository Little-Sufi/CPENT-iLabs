### Scenario

**Medical IoT Protocol Dissection** focuses on analyzing proprietary or medical device network protocols like **DICOM** (Digital Imaging and Communications in Medicine). Developing custom **Lua dissectors** for Wireshark enables penetration testers to parse unencrypted medical image transfers, extract PDU structures, and inspect raw traffic on healthcare IoT networks.

Key technical concepts in DICOM protocol dissection:
1. **Wireshark Lua Subsystem**: Verifying Lua support under <font color="#ffd700"><b>Help -> About Wireshark</b></font> and checking protocol dissector tables under <font color="#ffd700"><b>Analyze -> Enabled Protocols</b></font>.
2. **DICOM PDU Structure**: Digital Imaging PDU headers contain:
   - **PDU Type** (`uint8`): 1=ASSOC Request, 2=ASSOC Accept, 3=ASSOC Reject, 4=Data, 5=RELEASE Request, 6=RELEASE Response, 7=ABORT.
   - **Message Length** (`uint16` / `uint32`): Length of payload segment.
3. **Orthanc Medical Server Deployment**: Installing open-source DICOM server Orthanc on Ubuntu (<font color="#ffd700"><b>sudo apt install orthanc</b></font>), verifying active DICOM port `4242` and Web API port <font color="#38bdf8"><b>0.0.0.0:8042</b></font> via `netstat -atn`.
4. **Lua Dissector Scripting**: Constructing custom Wireshark protocol objects using `Proto()`, registering `ProtoField` elements, mapping endianness parsing (`add_le` vs `add`), and attaching to port `4242` via `DissectorTable.get("tcp.port"):add(4242, dicom_protocol)`.

In this exercise, we log into **Ubuntu** (<font color="#c084fc"><b>Ubuntu</b></font> / <font color="#ff4d4d"><b>toor</b></font>), open Wireshark, inspect sample capture file <font color="#c084fc"><b>DICOM_C-ECHO-echoscu.pcap</b></font>, filter PUSH TCP packets (`tcp.flags.push == 1`), follow TCP stream, install **Orthanc** server, verify listening interface <font color="#38bdf8"><b>0.0.0.0:8042</b></font>, write a custom Lua dissector script, and compare packet rendering across Ubuntu and Windows Server 2022.

9. Write custom Lua dissector script for DICOM PDU parsing:
```lua
dicom_protocol = Proto("dicom-a", "DICOM A-Type message")

pdu_type = ProtoField.uint8("dicom-a.pdu_type", "pduType", base.DEC, {
    [1] = "ASSOC Request",
    [2] = "ASSOC Accept",
    [3] = "ASSOC Reject",
    [4] = "Data",
    [5] = "RELEASE Request",
    [6] = "RELEASE Response",
    [7] = "ABORT"
})

message_length = ProtoField.uint16("dicom-a.message_length", "messageLength", base.DEC)

dicom_protocol.fields = {pdu_type, message_length}

function dicom_protocol.dissector(buffer, pinfo, tree)
    pinfo.cols.protocol = dicom_protocol.name
    local subtree = tree:add(dicom_protocol, buffer(), "DICOM PDU")
    subtree:add_le(pdu_type, buffer(0,1))
    subtree:add(message_length, buffer(2,4))
end

local tcp_port = DissectorTable.get("tcp.port")
tcp_port:add(4242, dicom_protocol)
```
