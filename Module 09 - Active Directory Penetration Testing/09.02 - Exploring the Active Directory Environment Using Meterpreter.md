# 🛡️ Module 09: Active Directory Penetration Testing

```bash
# Exercise 02: Exploring the Active Directory Environment Using Meterpreter
```

### Scenario

Once an initial foothold is established within an Active Directory domain, post-exploitation enumeration provides complete visibility into domain controllers, computers, logged-on users, and token privileges. Metasploit Framework and Meterpreter offer specialized gathering modules (`enum_domain`, `enum_ad_computers`, `enum_logged_on_users`, `enum_domain_tokens`), extended API plugins (`extapi` for UI window enumeration), and mimikatz/kiwi credential dumping modules (`lsa_dump_secrets`, `hashdump`, `cachedump`, `sekurlsa::logonpasswords`).

Furthermore, attackers can abuse domain privileges to construct **Golden Tickets** (Kerberos TGT tickets signed with the `krbtgt` account hash, granting persistent enterprise domain admin access) and **Silver Tickets** (Kerberos TGS tickets signed with service account hashes such as HTTP or WSMan for target services on specific domain controllers). In this exercise, we establish a Meterpreter shell on **Windows Server 2016**, escalate privileges to `NT AUTHORITY\SYSTEM`, dump LSA secrets and NTLM hashes, generate Golden and Silver tickets using `mimikatz.exe`, and test share access (`net use j: \\server2019.lpt.com\c$`) against the Domain Controller (<font color="#38bdf8"><b>server2019.lpt.com</b></font>).

### Objective

The objective of this lab is to help students learn how to:
- Establish a Meterpreter reverse TCP session on Windows Server 2016 using `msfvenom` and Metasploit multi/handler
- Execute Active Directory gathering modules (<font color="#ffd700"><b>enum_domain</b></font>, <font color="#ffd700"><b>enum_ad_computers</b></font>, <font color="#ffd700"><b>enum_logged_on_users</b></font>, <font color="#ffd700"><b>enum_domain_tokens</b></font>)
- Load extended API extensions (<font color="#ffd700"><b>load extapi</b></font>) and enumerate open GUI windows (<font color="#ffd700"><b>window_enum</b></font>)
- Perform local privilege escalation to `NT AUTHORITY\SYSTEM` (<font color="#ffd700"><b>getsystem</b></font>) and dump secrets/hashes (<font color="#ffd700"><b>lsa_dump_secrets</b></font>, <font color="#ffd700"><b>hashdump</b></font>, <font color="#ffd700"><b>cachedump</b></font>)
- Add domain persistence via Metasploit modules (<font color="#ffd700"><b>add_user</b></font>) and native net commands (<font color="#ffd700"><b>net user tester P@@12345 /ADD</b></font>)
- Extract domain SID details using Sysinternals PSTools (<font color="#ffd700"><b>psgetsid64.exe -accepteula lpt.com</b></font>)
- Generate and purge Golden Tickets in Mimikatz (<font color="#ffd700"><b>kerberos::golden /admin:Administrator /domain:lpt.com ... /ptt</b></font>)
- Mount remote administrative network shares (<font color="#ffd700"><b>net use j: \\server2019.lpt.com\c$</b></font>) targeting Domain Controller <font color="#38bdf8"><b>server2019.lpt.com</b></font>
- Construct Silver Tickets for HTTP and WSMan services on <font color="#38bdf8"><b>server2019\lpt.com</b></font>
