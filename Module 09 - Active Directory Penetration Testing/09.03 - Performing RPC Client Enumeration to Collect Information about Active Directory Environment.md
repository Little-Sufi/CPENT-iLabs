# Exercise 03: Performing RPC Client Enumeration to Collect Information about Active Directory Environment

### Scenario

Remote Procedure Call (RPC) interfaces exposed on Windows Domain Controllers (`MSRPC` on TCP port `135` / SMB named pipes `445`) allow authenticated users to perform low-level administrative and directory queries using the `rpcclient` utility. Through RPC calls, penetration testers can enumerate domain user account Relative Identifiers (RIDs), privilege tokens, group memberships, domain password policies, and network shares without relying on complex GUI tools or noisy scanning suites.

In this exercise, we utilize `rpcclient` from **Parrot Security** to interact with the target Windows Server 2019 Domain Controller (<font color="#38bdf8"><b>192.168.177.19</b></font>). We perform user enumeration (`enumdomusers`), inspect token privileges (`enumprivs`), query user account properties via RID (`queryuser 0xc3a`, `queryuser 0x1f4`), discover domain groups (`enumdomgroups`), enumerate SMB shares (`netshareenumall`), extract domain password policy (`getusrdompwinfo 0x1f4`), and retrieve the primary Domain Controller name (`getdcname LPT`).

### Objective

The objective of this lab is to help students learn how to:
- Establish an authenticated RPC connection to target Domain Controller <font color="#38bdf8"><b>192.168.177.19</b></font> using <font color="#ffd700"><b>rpcclient -U Hand 192.168.177.19</b></font>
- Enumerate all domain accounts (<font color="#ffd700"><b>enumdomusers</b></font>) and extract user RIDs (e.g., `jdoe` RID: <font color="#ffd700"><b>[0xe3c]</b></font>)
- Inspect user privileges and delegation rights (<font color="#ffd700"><b>enumprivs</b></font>)
- Query detailed account metadata for specific RIDs using <font color="#ffd700"><b>queryuser 0xc3a</b></font> (user `Hand`) and <font color="#ffd700"><b>queryuser 0x1f4</b></font> (`Administrator`)
- Enumerate domain structures (<font color="#ffd700"><b>enumdomains</b></font>) and domain group memberships (<font color="#ffd700"><b>enumdomgroups</b></font>)
- Connect as Domain Administrator using <font color="#ffd700"><b>rpcclient -U Administrator 192.168.177.19</b></font>
- Enumerate all active SMB network shares using <font color="#ffd700"><b>netshareenumall</b></font>
- Extract domain password complexity policy via <font color="#ffd700"><b>getusrdompwinfo 0x1f4</b></font>
- Discover the primary Domain Controller netbios/DNS name using <font color="#ffd700"><b>getdcname LPT</b></font>
