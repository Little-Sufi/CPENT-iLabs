### Scenario

**Overpass-the-Hash (OtH)**, also referred to as **Pass-the-Key**, bridges NTLM credential harvesting and Kerberos ticket request workflows. Instead of directly injecting NTLM hashes or stealing existing `.kirbi` tickets from memory, Overpass-the-Hash uses an extracted **NTLM hash**, **SHA1 key**, or **AES256 encryption key** to perform a standard AS-REQ request directly against the Key Distribution Center (KDC). The DC decrypts the timestamp using the supplied key and issues a brand-new, valid **Ticket Granting Ticket (TGT)** for the target user session.

In this exercise, we log into **2019DC** (<font color="#38bdf8"><b>LPT</b></font>\<font color="#c084fc"><b>Administrator</b></font> / <font color="#ff4d4d"><b>Pa$$w0rd</b></font>), run **Mimikatz** (`mimikatz.exe`), enable debug privileges (<font color="#ffd700"><b>privilege::debug</b></font>), dump logon credentials from LSASS memory using <font color="#ffd700"><b>sekurlsa::logonpasswords</b></font>, extract the SHA1 hash and AES256 ticket encryption key, invoke Mimikatz PtH module (<font color="#ffd700"><b>sekurlsa::pth /user:Administrator /domain:LPT.com /sha1:[SHA1_HASH] /aes256:[AES256_KEY]</b></font>), request a fresh Kerberos TGT from the KDC, and spawn an elevated command shell session.

### Objective

The objective of this lab is to help students learn how to:
- Enable debug privileges in Mimikatz using <font color="#ffd700"><b>privilege::debug</b></font>
- Extract plaintext credentials, NTLM digests, and SHA1 hashes via <font color="#ffd700"><b>sekurlsa::logonpasswords</b></font>
- Inspect cached Kerberos tickets and extract Kerberos AES256 encryption keys via <font color="#ffd700"><b>sekurlsa::tickets</b></font>
- Understand the requirement of Kerberos AES256 / SHA1 keys when invoking PtH for Overpass-the-Hash
- Perform Overpass-the-Hash using <font color="#ffd700"><b>sekurlsa::pth /user:Administrator /domain:LPT.com /sha1:[SHA1_HASH] /aes256:[AES256_KEY]</b></font>
- Request a valid Kerberos TGT from the Domain Controller and launch an authenticated shell context

## Task 1: Dump LSASS Credentials with Mimikatz and Execute Overpass-the-Hash Attack

In this task, we dump LSASS credentials using `sekurlsa::logonpasswords`, extract Administrator SHA1 and AES256 keys, and execute `sekurlsa::pth` to obtain a Kerberos TGT and spawn an elevated command prompt.

### Lab Tasks

1. Switch to **2019DC** machine and log in with Domain Administrator credentials (<font color="#38bdf8"><b>LPT</b></font>\<font color="#c084fc"><b>Administrator</b></font> / <font color="#ff4d4d"><b>Pa$$w0rd</b></font>). Navigate to `Downloads\kerberos\x64` and launch `mimikatz.exe`.

   <font color="#ffd700"><b>privilege::debug</b></font>
