### Scenario

Active Directory domain identification and credential brute-forcing across Server Message Block (SMB) protocols form critical early steps in network security assessments. By scanning LDAP services (`TCP 389`) across subnet ranges, penetration testers can quickly pinpoint active Domain Controllers and extract domain metadata, operating system builds, and primary FQDNs.

Once a Domain Controller is located, utility suites such as **NetExec** (`nxc`) allow testers to audit SMB authentication services (`TCP 445`), evaluate password spraying vulnerability using wordlists like `rockyou.txt`, enumerate hidden administrative disk shares (`--shares`), and verify share access over SMB (`smb://192.168.177.19/C$`). In this exercise, we scan the <font color="#38bdf8"><b>192.168.177.0/24</b></font> subnet with Nmap to discover Domain Controller <font color="#38bdf8"><b>192.168.177.19</b></font> (<font color="#38bdf8"><b>SERVER2019.lpt.com</b></font>), execute NetExec SMB password brute-forcing against <font color="#c084fc"><b>Administrator</b></font>, obtain valid credentials (<font color="#ff4d4d"><b>Pa$$w0rd</b></font>), enumerate administrative SMB shares, and establish GUI share access to `C$` via GTK file manager.

### Objective

The objective of this lab is to help students learn how to:
- Identify Active Directory Domain Controllers on a subnet using aggressive LDAP port scanning (<font color="#ffd700"><b>sudo nmap -p 389 -T4 -A 192.168.177.0/24</b></font>)
- Extract DC FQDN details (<font color="#38bdf8"><b>SERVER2019.lpt.com</b></font>) from Nmap script LDAP outputs
- Verify target SMB service availability using NetExec (<font color="#ffd700"><b>nxc smb 192.168.177.19</b></font>)
- Execute targeted dictionary attacks against domain accounts using NetExec: <font color="#ffd700"><b>nxc smb 192.168.177.19 -u 'Administrator' -p /usr/share/wordlists/rockyou.txt --ignore-pw-decoding</b></font>
- Enumerate SMB share permissions with valid domain credentials via <font color="#ffd700"><b>nxc smb 192.168.177.19 -u 'Administrator' -p 'Pa$$w0rd' --shares</b></font>
- Mount remote administrative shares using SMB GUI path (<font color="#38bdf8"><b>smb://192.168.177.19/C$</b></font>) and validate administrative access
