# 🛡️ Module 09: Active Directory Penetration Testing

```bash
# Exercise 04: Performing Active Directory Enumeration using PowerShell
```

### Scenario

PowerShell script modules such as **PowerView** (`PowerView.ps1`) and native RSAT Active Directory cmdlets (`ActiveDirectory`) provide comprehensive situational awareness during Windows domain assessments. PowerView queries Active Directory via LDAP, extracting domain metadata, computer accounts, domain groups, Kerberos policies, password last set timestamps, and `useraccountcontrol` flags.

Identifying domain accounts configured with **"Do not require Kerberos preauthentication"** (UAC flag `DONT_REQUIRE_PREAUTH` / `528384` or bit `0x10000`) enables **AS-REP Roasting** attacks. An unauthenticated attacker can request an AS-REP ticket for such users and attempt offline cracking against the ticket's encrypted section without needing a domain user password to initiate the request. In this exercise, we configure execution policy bypass in PowerShell on **2019DC**, import `PowerView.ps1`, enumerate AD domain policies and user accounts, configure AS-REP roasting eligibility on user `CPENT`, and analyze `useraccountcontrol` properties alongside native `ActiveDirectory` cmdlets.

### Objective

The objective of this lab is to help students learn how to:
- Bypass PowerShell script execution policies using <font color="#ffd700"><b>set-executionpolicy Bypass</b></font>
- Load PowerView module into PowerShell session via <font color="#ffd700"><b>import-module .\PowerView.ps1</b></font>
- Enumerate core domain details using <font color="#ffd700"><b>Get-Domain</b></font>
- Retrieve domain computer assets (<font color="#ffd700"><b>Get-domaincomputer</b></font>) and domain groups (<font color="#ffd700"><b>Get-domaingroup</b></font>)
- Extract domain password and lockout policies using <font color="#ffd700"><b>Get-domainpolicy</b></font>
- Track password last set timestamps in chronological order via <font color="#ffd700"><b>Get-NetUser -Properties pwdlastset</b></font>
- Enumerate domain user properties (<font color="#ffd700"><b>Get-NetUser</b></font>) and identify user UserPrincipalNames (e.g., `jdoe`: <font color="#ffd700"><b>jdoe@lpt.com</b></font>)
- Disable Kerberos Pre-authentication in Active Directory Users and Computers (ADUC) for user `CPENT`
- Inspect `useraccountcontrol` flags in PowerView to detect AS-REP Roasting misconfigurations
- Import and inspect native PowerShell RSAT modules using <font color="#ffd700"><b>Import-Module ActiveDirectory</b></font> and <font color="#ffd700"><b>Get-Command -Module ActiveDirectory</b></font>
