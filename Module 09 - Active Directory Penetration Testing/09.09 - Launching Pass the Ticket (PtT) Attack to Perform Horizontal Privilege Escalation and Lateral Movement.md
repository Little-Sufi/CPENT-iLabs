# Exercise 09: Launching Pass the Ticket (PtT) Attack to Perform Horizontal Privilege Escalation and Lateral Movement

### Scenario

**Pass-the-Ticket (PtT)** is an exploitation technique where an attacker extracts valid Kerberos **Ticket Granting Tickets (TGTs)** or **Service Tickets (TGSs)** from LSASS process memory and injects them into the current Windows logon session (`LSA`). Because Kerberos tickets are cryptographic tokens issued by the Key Distribution Center (KDC) to prove identity, injecting a stolen Ticket Granting Ticket bypasses NTLM challenge-response authentication entirely and grants the attacker immediate domain administrator privileges across target systems without needing plaintext passwords or password hashes.

In this exercise, we log into **2019DC** as <font color="#c084fc"><b>Administrator</b></font> (<font color="#ff4d4d"><b>Pa$$w0rd</b></font>), launch **Mimikatz** with administrative privileges, enable debug rights (<font color="#ffd700"><b>privilege::debug</b></font>), export all cached Kerberos `.kirbi` tickets from memory (<font color="#ffd700"><b>sekurlsa::tickets /export</b></font>), identify the Domain Administrator ticket, inject the ticket into the current memory session (<font color="#ffd700"><b>kerberos::ptt [TICKET_FILE.kirbi]</b></font>), list active session tickets (<font color="#ffd700"><b>kerberos::list</b></font>), disable Windows Firewall on target **Windows 11**, and leverage Sysinternals **PsExec** (<font color="#ffd700"><b>psexec.exe \\windows11 cmd.exe</b></font>) to execute remote shell commands laterally across the domain.

### Objective

The objective of this lab is to help students learn how to:
- Inspect MITRE ATT&CK Framework technique **T1550.003** (Pass the Ticket)
- Enable process debug privileges in Mimikatz using <font color="#ffd700"><b>privilege::debug</b></font>
- Inspect active Kerberos ticket caches across system users using <font color="#ffd700"><b>sekurlsa::tickets</b></font>
- Export Kerberos `.kirbi` ticket files to local disk via <font color="#ffd700"><b>sekurlsa::tickets /export</b></font>
- Inject stolen Kerberos TGT into current logon session using <font color="#ffd700"><b>kerberos::ptt [PATH_TO_TICKET.kirbi]</b></font>
- Display and verify active loaded Kerberos tickets in memory using <font color="#ffd700"><b>kerberos::list</b></font>
- Disable Windows Defender Firewall on target host `WINDOWS11`
- Perform lateral movement using PsExec (<font color="#ffd700"><b>psexec.exe \\windows11 cmd.exe</b></font>) to achieve remote command execution
