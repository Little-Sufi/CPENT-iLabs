### Scenario

Active Directory (AD) manages identity, access, and security policies across enterprise Windows environments. However, misconfigurations in Service Principal Names (SPNs), weak service account passwords, and legacy Kerberos ticketing mechanisms expose domain environments to **Kerberoasting** attacks. Kerberoasting allows any domain-authenticated user to request Kerberos TGS (Ticket Granting Service) tickets for SPN-associated service accounts and attempt offline password cracking against the TGS ticket hash (encrypted with the service account's NTLM hash).

In this exercise, we explore domain enumeration using native Windows utilities (`net user /domain`), set up a vulnerable service principal name using `setspn`, execute Kerberoasting across multiple operating system builds (**2019DC**, **Windows Server 2016**, and **Parrot Security**) using PowerShell (`Invoke-Kerberoast.ps1`, `RiskySPNs.psm1`), compiled C# binaries (`Rubeus.exe`), Impacket (`GetUserSPNs.py`), and Metasploit framework modules.

### Objective

The objective of this lab is to help students learn how to:
- Enumerate Active Directory users, groups, and domain details using native net commands (<font color="#ffd700"><b>net user</b></font>, <font color="#ffd700"><b>net user /domain</b></font>, <font color="#ffd700"><b>net user user-one /domain</b></font>)
- Configure Service Principal Names (SPNs) for target service accounts using <font color="#ffd700"><b>setspn -s http://LPT.com:80 user-one</b></font>
- Perform Kerberoasting via PowerShell using `Invoke-Kerberoast.ps1` and export Hashcat-formatted TGS hashes
- Bypass AMSI and PowerShell execution policies on Windows Server 2016 using TLS 1.2 WebRequest wrappers
- Compile and execute `Rubeus.exe` via Visual Studio 2019 to extract TGS hashes (<font color="#ffd700"><b>Rubeus.exe kerberoast /format:hashcat > Hashfile</b></font>) and clean whitespace formatting in Notepad++
- Import and execute `RiskySPNs.psm1` to identify crackable accounts (<font color="#ffd700"><b>Find-PotentiallyCrackableAccounts</b></font>)
- Execute remote Kerberoasting from Parrot Security using Impacket (<font color="#ffd700"><b>impacket-GetUserSPNs -request LPT.com/CPENT</b></font>) after domain time-synchronization
- Inspect Active Directory post-exploitation enumeration modules within Metasploit Framework
