### Scenario

Firewalls and Web Application Firewalls (WAF) inspect incoming packet structures, sizes, source ports, and hardware MAC vendor headers to enforce strict access control lists (ACLs). Security analysts and penetration testers evaluate firewall resiliency by executing specialized Nmap packet manipulation techniques designed to bypass inspection engines.

By applying packet fragmentation (<font color="#ffd700"><b>nmap -f certifiedhacker.com</b></font>), setting custom Maximum Transmission Units (<font color="#ffd700"><b>nmap -mtu 24 certifiedhacker.com</b></font>), spoofing trusted source service ports (<font color="#ffd700"><b>nmap --source-port 53 certifiedhacker.com</b></font>), and spoofing Ethernet MAC vendor headers (<font color="#ffd700"><b>nmap -sT -Pn --spoof-mac Dell certifiedhacker.com</b></font>), analysts evaluate how firewalls handle anomalous packet structures. Scanning the target domain <font color="#38bdf8"><b>certifiedhacker.com</b></font> reveals its resolved IP address: <font color="#38bdf8"><b>162.241.216.11</b></font>.

In this exercise, we execute SYN stealth and OS detection scans against <font color="#38bdf8"><b>certifiedhacker.com</b></font>, resolve target IP <font color="#38bdf8"><b>162.241.216.11</b></font>, perform port-specific probing, and apply packet fragmentation, MTU tuning, source port spoofing, and MAC address spoofing to enumerate ACL rules.

### Objective

The objective of this lab is to help students learn how to:
- Perform TCP SYN stealth scans and OS identification using Nmap (<font color="#ffd700"><b>nmap -sS -O certifiedhacker.com</b></font>)
- Identify the public target IP address of <font color="#38bdf8"><b>certifiedhacker.com</b></font> (<font color="#38bdf8"><b>162.241.216.11</b></font>)
- Execute port-filtered Nmap scans (<font color="#ffd700"><b>nmap -sS -O certifiedhacker.com -p 80</b></font>)
- Evade packet inspection filters using IP packet fragmentation (<font color="#ffd700"><b>nmap -f certifiedhacker.com</b></font>)
- Configure custom packet MTU boundaries (<font color="#ffd700"><b>nmap -mtu 24 certifiedhacker.com</b></font>)
- Bypass ACL filtering rules using trusted source port spoofing (<font color="#ffd700"><b>nmap --source-port 53 certifiedhacker.com</b></font>)
- Execute MAC vendor hardware address spoofing (<font color="#ffd700"><b>nmap -sT -Pn --spoof-mac Dell certifiedhacker.com</b></font>)
