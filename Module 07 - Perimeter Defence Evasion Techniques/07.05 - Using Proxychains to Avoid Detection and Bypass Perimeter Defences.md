# Exercise 05: Using Proxychains to Avoid Detection and Bypass Perimeter Defences

### Scenario

Perimeter security infrastructure—such as firewalls, Intrusion Prevention Systems (IPS), and geolocation filters—frequently block scanning requests or direct connections originating from untrusted, unauthorized IP addresses. To conceal source attribution and bypass IP-based access filters, security testers route network traffic through intermediate proxies using **Proxychains**.

By configuring a local SOCKS proxy listener (such as Metasploit's <font color="#c084fc"><b>auxiliary/server/socks_proxy</b></font> bound to TCP port <font color="#c084fc"><b>9050</b></font>) and chaining traffic through <font color="#c084fc"><b>/etc/proxychains.conf</b></font>, scanning utilities like Nmap (<font color="#ffd700"><b>sudo proxychains nmap -sS 192.168.0.51</b></font>) transparently route requests through intermediate proxy hops. Scanning target machines (such as the FTP Server at <font color="#38bdf8"><b>192.168.0.9</b></font>) via Proxychains reveals active listening services and identifies <font color="#ffd700"><b>6</b></font> open ports.

In this exercise, we review `/etc/proxychains.conf`, launch a SOCKS proxy server on port <font color="#c084fc"><b>9050</b></font> using Metasploit, verify port binding with `netstat`, execute Nmap scans through Proxychains against target IPs (<font color="#38bdf8"><b>192.168.0.51</b></font> and <font color="#38bdf8"><b>192.168.0.9</b></font>), and identify <font color="#ffd700"><b>6</b></font> open ports on the target.

### Objective

The objective of this lab is to help students learn how to:
- Inspect and configure Proxychains settings in <font color="#c084fc"><b>/etc/proxychains.conf</b></font>
- Deploy Metasploit's SOCKS proxy auxiliary module (<font color="#c084fc"><b>auxiliary/server/socks_proxy</b></font>)
- Configure SOCKS proxy listening ports (<font color="#ffd700"><b>set SRVPORT 9050</b></font>)
- Verify active proxy listening ports using <font color="#ffd700"><b>sudo netstat -atn</b></font>
- Execute stealth SYN scans through SOCKS proxy chains (<font color="#ffd700"><b>sudo proxychains nmap -sS 192.168.0.51</b></font>)
- Determine open port counts (<font color="#ffd700"><b>6</b></font>) on target systems behind proxy chains
