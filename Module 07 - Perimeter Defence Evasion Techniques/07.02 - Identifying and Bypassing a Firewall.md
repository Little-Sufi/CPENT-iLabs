### Scenario

Host-based and network firewalls inspect incoming and outgoing packets against configured rule lists, dropping unauthorized traffic and blocking diagnostic probes like ICMP traceroute requests. However, misconfigured firewalls often permit specific service ports (e.g., HTTP port 80, FTP port 21) or fail to block advanced TCP SYN probe techniques.

Penetration testers leverage specialized techniques such as **Firewalking** and raw packet probing with **Hping3** to analyze packet decay, discover open transit ports, and map active listening services behind filtering boundaries. By executing Nmap script engine (NSE) firewalk probes (<font color="#ffd700"><b>sudo nmap --script=firewalk --traceroute 172.19.19.7</b></font>) and TCP SYN incrementing probes (<font color="#ffd700"><b>sudo hping3 -S 172.19.19.7 -c 100 -p ++1</b></font>), security analysts can determine the exact filter boundaries and identify accessible ports for targeted exploitation.

In this exercise, we enable Windows Firewall on the Web Server machine (<font color="#38bdf8"><b>172.19.19.7</b></font>), observe traceroute blocking on Parrot Security, perform Nmap firewalking to uncover <font color="#ffd700"><b>8</b></font> open ports, and probe port responses across filtered ranges using Hping3.

### Objective

The objective of this lab is to help students learn how to:
- Configure host-based Windows Firewall settings across all network profiles on the Web Server
- Test target reachability using standard ICMP ping (<font color="#ffd700"><b>ping 172.19.19.7</b></font>) and analyze UDP/ICMP traceroute filtering (<font color="#ffd700"><b>traceroute 172.19.19.7</b></font>)
- Execute advanced Nmap firewalking scripts to determine gateway control rules and identify open ports (<font color="#ffd700"><b>sudo nmap --script=firewalk --traceroute 172.19.19.7</b></font>)
- Identify the total count of open ports (<font color="#ffd700"><b>8</b></font>) reported during active Nmap firewalk discovery
- Perform incremental TCP SYN packet probing using Hping3 (<font color="#ffd700"><b>sudo hping3 -S 172.19.19.7 -c 100 -p ++1</b></font>) to distinguish open vs. filtered ports
