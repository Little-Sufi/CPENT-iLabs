### Scenario

Host-based anti-malware protections (such as Windows Defender) actively monitor process memory and disk write operations to detect known signature patterns and malicious executables. Client-side evasion tactics leverage native script interpreters—such as PowerShell—to dynamically execute shellcode directly within host memory without creating persistent files on disk.

The **Social-Engineer Toolkit (SET)** provides specialized PowerShell Attack Vectors designed to bypass host endpoint protections. By accessing SET module menu option **1** (*Social-Engineering Attacks*) and selecting menu option **9** (<font color="#ffd700"><b>9</b></font>, *PowerShell Attack Vectors*), security testers can generate obfuscated PowerShell shellcode payloads (<font color="#c084fc"><b>x86_powershell_injection.txt</b></font>). When executed on a target host like Windows Server 2019, the payload establishes an outbound encrypted Meterpreter session back to the handler listening on port <font color="#c084fc"><b>443</b></font>.

In this exercise, we initialize SET on Parrot Security, generate a PowerShell injection payload using menu option <font color="#ffd700"><b>9</b></font>, start an automated Metasploit payload handler on port <font color="#c084fc"><b>443</b></font>, transfer and execute the script in PowerShell on Windows Server 2019, and establish an active Meterpreter shell.

### Objective

The objective of this lab is to help students learn how to:
- Launch and configure the **Social-Engineer Toolkit (SET)** (<font color="#ffd700"><b>sudo setoolkit</b></font>)
- Navigate SET attack vector menus to locate PowerShell Attack Vectors (Option **1** $ightarrow$ Option <font color="#ffd700"><b>9</b></font>)
- Generate memory-injection PowerShell payloads targeting Windows host platforms
- Configure custom reverse TCP payload handlers listening on port <font color="#c084fc"><b>443</b></font>
- Locate generated SET report files in hidden directory paths (<font color="#c084fc"><b>/root/.set/reports/powershell/x86_powershell_injection.txt</b></font>)
- Execute PowerShell payloads on Windows Server 2019 to obtain interactive **Meterpreter** sessions
