### Scenario

Perimeter defense mechanisms, such as stateful firewalls, access control lists (ACLs), and intrusion detection systems (IDS), actively inspect and filter incoming network traffic. When default security policies block or drop packets, standard active port scans fail or return ambiguous results.

To assess target attack surfaces effectively, penetration testers must evaluate how filtering devices behave under various configurations. By observing traffic patterns in protocol analyzers (such as Wireshark) while adjusting netfilter/iptables policies on target hosts—transitioning from open policies to explicit packet dropping (<font color="#ffd700"><b>DROP</b></font>) or ICMP prohibition responses (<font color="#ffd700"><b>REJECT --reject-with icmp-host-prohibited</b></font>)—testers can detect the presence of intermediary filters and formulate advanced evasion scanning strategies.

In this exercise, we initialize Wireshark on Parrot Security to capture traffic targeting an Ubuntu server (<font color="#38bdf8"><b>192.168.0.51</b></font>), configure iptables policies on Ubuntu to drop incoming packets using the <font color="#ffd700"><b>DROP</b></font> target, observe scanning anomalies with Nmap (<font color="#ffd700"><b>nmap -sC 192.168.0.51 -n</b></font>), and analyze ICMP host-prohibited firewall responses in Wireshark.

### Objective

The objective of this lab is to help students learn how to:
- Capture and analyze raw network protocol traffic using Wireshark on network interface <font color="#c084fc"><b>eth0</b></font>
- Perform initial target ping probes and active service discovery scans using Nmap (<font color="#ffd700"><b>nmap -sC 192.168.0.51 -n</b></font>)
- Configure Linux netfilter/iptables default input chain policies to silently discard packets using the <font color="#ffd700"><b>DROP</b></font> target
- Observe Nmap scanning behavior and packet timeout characteristics against drop-filtered targets
- Configure iptables ICMP host-prohibited rules (<font color="#ffd700"><b>-j REJECT --reject-with icmp-host-prohibited</b></font>) to emulate router ACL responses

## Task 1: Analyze Filtering Behavior with Wireshark and Nmap

In this task, we capture ICMP and TCP traffic in Wireshark on Parrot Security, alter netfilter input policies on Ubuntu to enforce traffic drops using <font color="#ffd700"><b>DROP</b></font>, evaluate Nmap scan output against filtered targets, and emulate perimeter ACL responses using ICMP rejection rules.

    <font color="#ffd700"><b>sudo iptables -P INPUT ACCEPT</b></font>
