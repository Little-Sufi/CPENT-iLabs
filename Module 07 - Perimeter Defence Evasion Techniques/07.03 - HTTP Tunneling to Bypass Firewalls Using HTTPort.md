### Scenario

Perimeter firewalls and egress filtering policies frequently restrict outbound high-risk protocol ports (such as FTP port 21), while allowing unencrypted HTTP (TCP port 80) traffic to ensure essential web connectivity. Attackers leverage **HTTP Tunneling** techniques to encapsulate restricted protocol streams inside allowed HTTP requests/responses, effectively bypassing strict egress firewall controls and network intrusion prevention systems.

Using **HTTPort** on a restricted client and **HTTHost** on an intermediate gateway server, egress traffic targeting blocked destination services (e.g., FTP server at <font color="#38bdf8"><b>172.19.19.17</b></font>) can be proxied and encapsulated across standard HTTP sessions listening on port 80 (<font color="#38bdf8"><b>172.19.19.9:80</b></font>). Configuring personal authentication passwords in HTTHost's **Options** tab (<font color="#ffd700"><b>options</b></font>) ensures secure, authenticated tunnel proxying.

In this exercise, we stop IIS web services and run HTTHost on the FTP Server (<font color="#38bdf8"><b>172.19.19.9</b></font>), configure an outbound Port 21 blocking firewall rule on Windows Server 2022, configure HTTPort proxy and port mapping settings to target Sales Department (<font color="#38bdf8"><b>172.19.19.17</b></font>), execute localhost FTP connections (<font color="#ffd700"><b>ftp 127.0.0.1</b></font>), and verify directory creation through the HTTP tunnel.

### Objective

The objective of this lab is to help students learn how to:
- Configure **HTTHost** listener services on remote intermediate servers (<font color="#38bdf8"><b>172.19.19.9:80</b></font>)
- Identify the personal password configuration interface in HTTHost (**Options** tab $ightarrow$ <font color="#ffd700"><b>options</b></font>)
- Configure Windows Defender Firewall Advanced Outbound Rules to block destination FTP port 21
- Verify egress firewall block enforcement against direct target IPs (<font color="#38bdf8"><b>172.19.19.17:21</b></font>)
- Install and configure **HTTPort** proxy settings, bypass host parameters, and port mappings
- Tunnel FTP traffic via localhost (<font color="#ffd700"><b>ftp 127.0.0.1</b></font>) through HTTPort/HTTHost to authenticate and interact with remote file systems
